# 一 git基本命令

* git clone 地址 : clone 代码库 

* git init : 初始化

* git add -A : 添加文件到cvs

* git commit -m 注释 : commit文件

* git push : push文件

* git pull : 更新文件

* git fetch : 获取更新，但不更新文件

# 二 分支操作

* git push -u origin 分支名称 : 推送本地分支到远程

* git push --set-upstream origin 分支名称 : 推送本地分支到远程

* git branch : 显示本地分支

* git checkout 分支名称 : 切换分支

* git checkout -b 分支名称 : 从当前分支拉一个分支

* git merge origin/xxx : xxx分支合并到本地分支

* git branch -m 新分支名称 : 重命名本地分支

* git push origin --delete 远程分支名称 : 删除原称分支

# 三  tag操作

* git tag -A 版本号 -m 注释 : 打一个tag

* git push origin tagname : 推送tag到远程

# 四 修改分支名称

## 一 修改本地分支

1. git checkout 分支名称 : 切换到要修改的分支

2. git branch -m 新分支名称 : 修改本地分支名称

## 二 修改远程分支

3. git push origin --delete 分支名称 : 删除旧分支

4. git push -u origin 新分支名称 : 将远程上游分支修改为本地分支 

# 五 github clone/push配置

## 方式一 HTTPS + Personal Access Token（PAT) 

不稳定，不推荐

## 方式二 SSH Key

长期稳定，首选

### 一 生成 SSH Key（cmd）

```shell
ssh-keygen -t ed25519 -C "xxx@gmail.com"
```

一路回车，不用设置密码，生成路径：

```
C:\Users\你的用户名\.ssh\id_ed25519
C:\Users\你的用户名\.ssh\id_ed25519.pub
```

### 二 把公钥加入到Github

查看公钥：

```shell
type %USERPROFILE%\.ssh\id_ed25519.pub
```

复制全部内容 → GitHub：**Settings → SSH and GPG keys → New SSH key**

### 三 测试连接

```shell
ssh -T git@github.com
```

### 四 使用SSH clone （以后不需要密码）

```shell
git clone git@github.com:用户名/仓库名.git
```

### 五 注意点

* 换电脑后 **SSH 必须重新配置**

*  Failed to connect / timeout

  检查：

  ```shell
  git config --global --get http.proxy
  git config --global --get https.proxy
  ```

  如果有：

  ```shell
  git config --global --unset http.proxy
  git config --global --unset https.proxy
  ```
